# GCC Philanthropy, Donors and Funders

A directory of 1,344 philanthropic funders, foundations, corporate giving programmes,
family offices and endowments in the United Arab Emirates, Saudi Arabia and Qatar.

Pick a country or a kind of funder, and the list for that selection opens with each
organisation's cause areas, location and published contact details.

Static site: one HTML file and one JSON file, no build step and no external requests.
